# Terraform Documentation

This document provides a comprehensible explanation of the use
of Terraform within the Whanos project.

## Core functionalities

### Kubernetes cluster
- The "make run-terraform" command will create a kubernetes cluster with a set amount of nodes and predetermined specs (note that it will also set up a VPS, but more on that later)
- This cluster will handle the deploying and scaling of your containerised applications
- If the cluster has already been created, the command will fail and provide an error message stating that a cluster with the same name already exists, which is normal
- To change those parametes as well as your cloud provider and many more, edit the relevant variables in "/terraform/main.tf" and / or "/terraform/terraform.tvars"

### VPS
- As mentionned before, "make run-terraform" will also create / set up a VPS server on which your applications will run
- Terraform will also provide Ansible (another tool used by Whanos, documentation at "/docs/ansible/ansible-hub.md") with all the informations that it needs regarding the VPS by editing "/ansible/group_vars/all.example.yml"
- Just like the kubernetes cluster, you will be able to change most parameters by simply editing variables within the files mentionned earlier

### Cleaning up
- The "make run-terraform-reset" command will erase all files generated by "make run-terraform", only use this if you wish to start over from scratch
